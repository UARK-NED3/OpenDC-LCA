# Contributing

Thank you for helping build an open benchmark for data-center cooling LCA.

1. Open an issue describing the scientific or software change.
2. Keep proprietary and licensed data outside the repository.
3. Add provenance metadata for every dataset.
4. Add or update tests for calculation changes.
5. Run `python -m unittest discover -s tests -v`.
6. Submit a focused pull request describing boundary and result changes.

Code should use SI units internally, type hints, and standard-library
dependencies unless a new dependency provides clear scientific value.

By contributing, you agree that your code and original documentation may be
distributed under the MIT License. Dataset contributions must state their own
license explicitly.
