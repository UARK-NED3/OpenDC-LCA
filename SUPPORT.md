# Support

- Usage and scientific questions:
  https://github.com/UARK-NED3/OpenDC-LCA/issues
- Security-sensitive reports: use GitHub's private security advisory interface.
- Data contributions must follow `CONTRIBUTING.md` and include provenance,
  uncertainty, review status, confidentiality, and redistribution permission.

OpenDC-LCA is research software, not a certification service. Users remain
responsible for goal and scope, inventory rights, critical review, and public
claims.
