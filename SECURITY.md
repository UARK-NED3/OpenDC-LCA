# Security policy

## Supported version

Security fixes are provided for the latest 1.x release.

## Reporting

Please use GitHub's private security-advisory interface rather than a public
issue for vulnerabilities.

## Local GUI

The GUI is designed for localhost use and has no authentication. Remote
binding requires an explicit flag and is not recommended. Do not expose it to
the public internet or use it to process confidential data over an untrusted
network.
